## THIS SESSION'S WORK

**P1 — the action layer and a keymap in the save** (`c4c7a51`, `9eea638`, `6953186`)
31 hardcoded `kb.addKey` sites across two scenes now resolve through a named-action table stored
in the save. `Input.ts` is **deliberately Phaser-free** — SaveStore imports it and SaveStore is
tested headless, and the first draft killed the 2896-assertion suite on `window is not defined`.
That split forced a **whitelist** of bindable keys, which turned out to be what a rebind screen
wanted anyway: "any key Phaser knows" includes `F5`.
Exactly **two slots per action** (Grok's best contribution) — every action already had two, and
`[string, string | null]` makes "a primary always exists" a type rather than a rule.
`handedness` lands **null = unasked**, which is what lets the question be asked exactly once.

**P2 — the JOURNAL** (`72757cb`)
Net-new 4th scene, opened by ESC **from the map only**: inside the pack ESC already means
close-and-cancel-split, and that is why Grok's "put settings on the Subscreen" was refused. It
copies Subscreen's proven pause/launch/resume pattern rather than inventing scene management.
Rebinding reads keys **straight from the DOM** via a one-shot listener, because the action layer
only knows keys already bound and the player is there to name one that is not. It reads
`ev.code`, so an AZERTY player binds the key they actually pressed.

**P3 — HOW TO PLAY, five animated diagrams** (`72757cb`)
Gemini's position, adopted: teach with diagrams, not prose. A key-cap fills, the sight rises,
arrows steer it, and the release throws in an eight-segment arc. **Proof it works:** rebinding
WALK UP to `Z` made the card read *"Z / W and the rest"* with the footer at *"Z MOVE"*, live.

**P4 — the throw** (`72757cb`)
Aiming moved off the overloaded hand keys onto `aim` (E/G). **No hold threshold** — the 220 ms
delay only ever existed to tell a tap from a hold on the *shared* key, so a dedicated key rises
on the press. The 220 ms idiom now lives in one place, the pack's split.
The hand is answered by **handedness**, not a key. Mouse aiming, with the **cursor-snap guard**.
`AIM_RANGE` became `throwRange(tile)` — a **seam only**; stats and weight are recorded, not
designed.
